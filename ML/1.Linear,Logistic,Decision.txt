Linear Regression

Linear Regression is used when the target variable is continuous, such as predicting price, revenue, or demand. After collecting and preprocessing the dataset (handling missing values, encoding categorical variables, and scaling features if necessary), the data is split into training and testing sets. The model learns the relationship between independent variables and the target by fitting a linear equation. During training, the model minimizes the loss function (typically Mean Squared Error) using gradient descent, which iteratively updates the coefficients to reduce prediction error. To prevent overfitting, regularization techniques such as L1 (Lasso) or L2 (Ridge) may be applied, where L1 can shrink some coefficients to zero for feature selection and L2 reduces coefficient magnitudes while keeping all features. Once trained, the model predicts values on unseen data, and performance is evaluated using regression metrics like Mean Absolute Error (MAE), Mean Squared Error (MSE), Root Mean Squared Error (RMSE), and R² score. Since linear regression predicts continuous outputs rather than classes, metrics like confusion matrix, ROC curve, and AUC are not typically used.

Logistic Regression

Logistic Regression is used for classification problems, typically binary classification such as fraud detection or disease prediction. After preprocessing the dataset and splitting it into training and testing sets, the model learns the relationship between features and the probability of belonging to a particular class. Instead of predicting a continuous value directly, logistic regression uses the sigmoid function to convert the linear combination of inputs into a probability between 0 and 1. The model parameters are optimized using gradient descent, minimizing the log loss (cross-entropy loss). To reduce overfitting and improve generalization, L1 or L2 regularization may be applied to penalize large coefficients. After training, the model outputs probabilities, which are converted into class labels using a threshold (commonly 0.5). Model performance is evaluated using a confusion matrix, which provides counts of True Positives, True Negatives, False Positives, and False Negatives. From this matrix, metrics like accuracy, precision, recall, and F1-score are calculated. Additionally, the model can be evaluated using the ROC (Receiver Operating Characteristic) curve, which plots the True Positive Rate against the False Positive Rate across different thresholds, and the AUC (Area Under the Curve) measures the model’s ability to distinguish between classes.

Decision Tree

A Decision Tree can be used for both classification and regression problems, but in classification tasks it works by recursively splitting the dataset into subsets based on feature values. After preprocessing and splitting the dataset into training and testing sets, the algorithm builds a tree structure where each internal node represents a decision rule and each leaf node represents a prediction. To determine the best feature to split at each step, the model calculates impurity measures such as Entropy or Gini Index. Information Gain is computed when entropy is used, representing the reduction in disorder after a split; the feature with the highest information gain (or lowest Gini impurity) is selected. This process continues recursively until stopping criteria are reached, such as maximum depth or minimum samples per node, which also helps prevent overfitting (similar in purpose to regularization). Once the tree is trained, predictions are made by following the decision rules from the root to a leaf node. For classification trees, the model is evaluated using a confusion matrix, from which accuracy, precision, recall, and F1-score are derived. The classifier’s discriminative ability can also be assessed using the ROC curve and AUC score. For regression trees, performance is measured using metrics such as MSE, MAE, and R².
