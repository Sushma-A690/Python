📓 Transformer & Embeddings – Notes
🔹 1. Types of Embeddings
Static Embeddings
Each word has a fixed vector representation
Same word → same embedding always
Example:
“bank” (river) = “bank” (finance) ❌ same vector
Generated during training phase
Do not change during inference
Contextual Embeddings
Word meaning depends on context
Same word → different embeddings based on sentence
Example:
“bank of river” ≠ “bank account” ✅
Generated using attention mechanism (Q, K, V)
🔹 2. Model Architecture Basics
Encoder Output
Output of encoder = Contextual Embeddings
Model Differences
BERT → Uses only encoder
GPT → Uses only decoder
🔹 3. Training vs Inference
Training Phase
Learn parameters:
𝑊𝑞,𝑊𝑘,𝑊𝑣	​

Done using:
Loss calculation
Backpropagation
Chain rule

✅ After training:

These matrices are fixed
No change during inference

Inference (Real-world usage)
Input sentence → embeddings → attention → output

In transformer models, each word in a sentence is first converted into a static embedding and combined with positional information to retain word order. These embeddings are then passed through learned weight matrices to generate query, key, and value vectors. The core idea is that each word’s query vector interacts with all other words’ key vectors using a dot product to determine how much attention it should pay to them. These attention scores are normalized using softmax to form probabilities, which are then used to weight the value vectors, producing a context-aware representation of each word. This process is repeated across multiple attention heads to capture different types of relationships such as semantic and syntactic dependencies. The output is further refined using feed-forward neural networks and normalization layers, resulting in rich contextual embeddings that understand the meaning of words based on their surrounding context.

Semantic = meaning of words/sentence
Focuses on what the sentence is trying to say
Example:
“I ate an apple” vs “I ate a fruit”
→ Same semantic meaning (apple is a fruit)
“bank”:
river bank
money bank
→ Different semantic meanings

Syntactic = sentence structure / grammar
Focuses on how words are arranged
Example:

“She is eating food” ✔️ (correct syntax)
“She eating is food” ❌ (wrong syntax)
Subject → Verb → Object pattern

In Attention (both matter)
Semantic → connects related words
(e.g., “rice” ↔ “dish”)
Syntactic → connects grammar roles
(e.g., “I” ↔ “made”)
